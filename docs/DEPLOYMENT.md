# Deployment Guide

This guide shows you how to run Personal-Assistant in production-like
environments, behind a reverse proxy, and with proper isolation.

## Recommended architecture

```
                      ┌──────────────────┐
   Browser ────▶ HTTPS ┤  nginx / Caddy   ┤  HTTP (localhost only)
                      │  (TLS + auth)    │─────────────┐
                      └──────────────────┘             ▼
                                            ┌──────────────────────┐
                                            │  pa-server (3000)    │
                                            │  Node 20+            │
                                            │  Express + SSE        │
                                            └──────┬───────────────┘
                                                   │
                                       ┌───────────┴──────────┐
                                       ▼                      ▼
                              ┌─────────────┐       ┌──────────────┐
                              │ ~/.config/  │       │  Upstream    │
                              │  config     │       │  LLM APIs    │
                              │  (0600)     │       │  (over HTTPS)│
                              └─────────────┘       └──────────────┘
```

**Never expose port 3000 directly to the public internet.** There is no
built-in auth in the current release.

## Reverse proxy + TLS

### nginx

```nginx
server {
  server_name  pa.example.com;
  listen 443 ssl http2;

  ssl_certificate     /etc/letsencrypt/live/pa.example.com/fullchain.pem;
  ssl_certificate_key /etc/letsencrypt/live/pa.example.com/privkey.pem;

  # Basic auth (optional)
  auth_basic           "Personal-Assistant";
  auth_basic_user_file /etc/nginx/.htpasswd;

  # SSE: disable buffering
  proxy_buffering         off;
  proxy_http_version      1.1;
  proxy_set_header        Connection           "";
  proxy_set_header        Host                 $host;
  proxy_set_header        X-Real-IP            $remote_addr;
  proxy_set_header        X-Forwarded-For      $proxy_add_x_forwarded_for;
  proxy_set_header        X-Forwarded-Proto    $scheme;
  proxy_read_timeout      86400;   # 1 day, keep SSE streams alive

  location / {
    proxy_pass http://127.0.0.1:3000;
  }
}

server {
  listen 80;
  server_name pa.example.com;
  return 301 https://$host$request_uri;
}
```

### Caddy

```caddyfile
pa.example.com {
  basicauth {
    admin $2a$14$…  # generated by `caddy hash-password`
  }
  reverse_proxy 127.0.0.1:3000 {
    flush_interval -1
    transport http {
      read_timeout 86400s
    }
  }
}
```

## Docker

A minimal `Dockerfile`:

```dockerfile
FROM node:20-alpine
WORKDIR /app
COPY package.json package-lock.json ./
RUN npm ci --omit=dev
COPY dist ./dist
COPY server ./server
COPY src ./src
ENV PORT=3000
EXPOSE 3000
USER node
CMD ["node", "dist/server/index.js"]
```

Build and run:

```bash
docker build -t personal-assistant .
docker run -d \
  --name pa \
  -p 127.0.0.1:3000:3000 \
  -v $HOME/.config/personal-assistant-nodejs:/home/node/.config/personal-assistant-nodejs:ro \
  -e OPENAI_API_KEY="$OPENAI_API_KEY" \
  --restart unless-stopped \
  personal-assistant
```

A `docker-compose.yml` is provided at [`docker-compose.yml`](../docker-compose.yml).

## systemd

`/etc/systemd/system/personal-assistant.service`:

```ini
[Unit]
Description=Personal-Assistant
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
User=pa
Group=pa
WorkingDirectory=/opt/personal-assistant
ExecStart=/usr/bin/node /opt/personal-assistant/dist/server/index.js
Restart=on-failure
RestartSec=5

# Security hardening
NoNewPrivileges=true
PrivateTmp=true
ProtectSystem=strict
ProtectHome=true
ReadWritePaths=/opt/personal-assistant/.runtime
ProtectKernelTunables=true
ProtectKernelModules=true
ProtectControlGroups=true
RestrictAddressFamilies=AF_UNIX AF_INET AF_INET6
RestrictNamespaces=true
RestrictRealtime=true
LockPersonality=true
MemoryDenyWriteExecute=true

# Environment
Environment=NODE_ENV=production
EnvironmentFile=-/etc/personal-assistant/env
StandardOutput=journal
StandardError=journal
SyslogIdentifier=personal-assistant

[Install]
WantedBy=multi-user.target
```

Enable and start:

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now personal-assistant
sudo journalctl -u personal-assistant -f
```

## Security checklist

Before exposing to any non-localhost client, verify each item:

- [ ] TLS enabled (Let's Encrypt / Cloudflare / etc.)
- [ ] Authentication (Basic Auth, OAuth proxy, mTLS, or VPN)
- [ ] Process runs as a non-root, dedicated user (`pa` or `node`)
- [ ] File-system permissions are 0700 for the home dir, 0600 for `config.json`
- [ ] `config.sandbox.allowedCommands` is restricted
- [ ] API keys are read from env or 0600-protected file (never env dumped)
- [ ] Logging redaction enabled (default: yes — `*.redact=true` in config)
- [ ] Firewall: only 443 open; 3000 bound to 127.0.0.1
- [ ] Dependabot security updates enabled
- [ ] `npm audit --production` clean in CI

## Monitoring & logs

### Logs

Default log target is stdout, JSON-formatted. Pipe to `journalctl`,
`vector`, or `fluent-bit`.

```bash
# journalctl
sudo journalctl -u personal-assistant -f --since "5 minutes ago"

# Pretty-print JSON logs
sudo journalctl -u personal-assistant -o cat | jq
```

### Health check

The server exposes a liveness endpoint:

```bash
curl -fsS http://127.0.0.1:3000/api/health
# {"status":"ok","uptime":12345,"providers":{...}}
```

Wire it into your monitoring system (Prometheus blackbox-exporter,
Uptime Kuma, etc.) with a 30-second interval.

### Metrics

A Prometheus-format `/metrics` endpoint is on the roadmap
(issue tracker). For now, scrape `process_cpu_seconds_total` and
`process_resident_memory_bytes` from the host.

## Backup & restore

The persistent state lives in two places:

1. **`~/.config/personal-assistant-nodejs/config.json`** (API keys, chat defaults, sandbox)
2. **`~/.local/share/personal-assistant-nodejs/memory/`** (MiniSearch index + memory entries)

Back these up to encrypted storage:

```bash
# One-off
tar -czf pa-backup-$(date +%F).tar.gz \
  ~/.config/personal-assistant-nodejs \
  ~/.local/share/personal-assistant-nodejs

# Automated (daily, 7-day retention)
echo '0 3 * * * tar -czf /backup/pa-$(date +\%F).tar.gz ~/.config/personal-assistant-nodejs ~/.local/share/personal-assistant-nodejs && find /backup -name "pa-*.tar.gz" -mtime +7 -delete' \
  | crontab -
```

Restore:

```bash
# Stop the server
sudo systemctl stop personal-assistant

# Extract
tar -xzf pa-backup-YYYY-MM-DD.tar.gz -C /

# Fix permissions
chmod 700 ~/.config/personal-assistant-nodejs
chmod 600 ~/.config/personal-assistant-nodejs/config.json

# Start
sudo systemctl start personal-assistant
```
